/helpers [set <role> <connector> <model> [effort]|off [role]|usage|run <role> <text>|compact|budget <calls> <tokens>]

Roles: compactor, extractor, verifier. Helpers are disabled by default.
Setting a role makes no model calls. Explicit run/compact makes one additional billable call, with at most one JSON repair.
Compactor configuration authorizes older conversation text to be sent to that named connector; opaque provider state is omitted.
Automatic compaction remains algorithmic. /helpers compact performs an explicit rollover and keeps two recent turns.
Budgets use conservative provider-capacity reservations; retries with missing usage remain unknown.
Usage lists purposes, known tokens/cost estimates and unknown usage; it is process-local diagnostic data.
